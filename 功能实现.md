## 第 0 章 先把交互方式定下来

### 0.1 一次操作到底走了哪几步

课件里已经定好了骨架：客户端用 `MessageSender` 发 `Message(command, data)`，服务端 `MessageProcessTask` 用 `switch` 认命令，处理完用 `SocketUtil.sendMsg` 把结果发回去。
后面的全部代码都只是往这个骨架里填内容：

1. 客户端 `UserAction` 收数据 → 封装成实体或 `Map` → `MessageSender.sendMsg(命令, 数据)`；
2. 服务端 `MessageProcessTask` 收到消息 → `switch` 分发 → 交给 `service` 包里的业务方法；
3. 业务方法返回一个结果（`Integer` 标识 / 实体 / `List`）→ 原样发回客户端；
4. 客户端根据返回的标识打印提示。

所以「功能实现」这一章真正要写的是两件事：**每个命令的业务方法**，和**每个命令的客户端行为**。

## 第 1 章 补齐公共层（不改这三处，后面写了也编译不过）

### 1.1 为什么先动公共层

课件里的实体只贴了字段（“此处省略了 get/set 方法”），而功能实现必须要用它们：

- 服务端要 `getUsername()`、`getState()`、`setState()` 这些方法才能做业务判断；
- `SocketUtil` 用的是**对象流**，`User`、`Film`、`FilmHall` 这些对象要真正在网络上传输，**必须实现 `Serializable`**，否则客户端一订座就报 `NotSerializableException`；
- 需要 `toString()` 打印列表，否则控制台输出的是一串内存地址。

下面是补全后的 8 个实体，直接替换 `cinema-platform-common` 里 `entity` 包中的同名文件。

> 说明：`User` 的字段用 `protected` 而不是 `private`，因为 `Seller extends User` 在构造时要给 `role`、`state` 赋值。

#### `entity/User.java`

```java
package org.zlf.cinema.platfrom.entity;

import java.io.Serializable;

//ER图 Entity Relational
//实体包常用包名：entity 实体 pojo(plain ordinary java object)简单java对象
//bo(business object) 业务对象 vo(view object) 视图对象 dto(data transfer object) 数据传输对象
//domain 领域模型  model 数据模型

/**
 * 用户
 */
public class User implements Serializable {
    /**
     * 用户角色：普通用户、管理员、商家
     */
    public enum Role{
        USER,MANAGER,SELLER
    }

    /**
     * 用户名
     */
    protected String username;
    /**
     * 密码
     */
    protected String password;
    /**
     * 安全码
     */
    protected String securityCode;
    /**
     * 角色：默认为普通用户
     */
    protected Role role;
    /**
     * 账号状态：-1-审核不通过，0-待审核，1-正常，2-冻结
     */
    protected int state;

    public User(String username, String password, String securityCode) {
        this.username = username;
        this.password = password;
        this.securityCode = securityCode;
        this.role = Role.USER;//默认为普通用户
        this.state = 1;//默认为正常
    }

    public String getUsername() {
        return username;
    }

    public String getPassword() {
        return password;
    }

    public void setPassword(String password) {
        this.password = password;
    }

    public String getSecurityCode() {
        return securityCode;
    }

    public void setSecurityCode(String securityCode) {
        this.securityCode = securityCode;
    }

    public Role getRole() {
        return role;
    }

    public void setRole(Role role) {
        this.role = role;
    }

    public int getState() {
        return state;
    }

    public void setState(int state) {
        this.state = state;
    }

    @Override
    public String toString() {
        String roleStr = role == Role.MANAGER ? "管理员" : "普通用户";
        String stateStr = state == -1 ? "审核不通过" : state == 0 ? "待审核" : state == 1 ? "正常" : "冻结";
        return username + "\t" + roleStr + "\t" + stateStr;
    }
}
```

#### `entity/FilmHall.java`

影厅是这一章的重点：座位图 `Seat[][]` 由总排数、总列数生成，余票、订座、退座、换座都在这里算。
`showSeatInfo()` 把已被订的座位打到 `System.err`，控制台里就是红色，一眼能看出哪些座位没了。

```java
package org.zlf.cinema.platfrom.entity;

import java.io.PrintStream;
import java.io.Serializable;

/**
 * 影厅
 */
public class FilmHall implements Serializable {
    /**
     * 编号
     */
    private String id;
    /**
     * 名称
     */
    private String name;
    /**
     * 总排数
     */
    private int totalRow;
    /**
     * 总列数
     */
    private int totalCol;
    /**
     * 座位列表
     */
    private Seat[][] seats;
    /**
     * 拥有者
     */
    private String owner;

    public FilmHall(String name, int totalRow, int totalCol, String owner) {
        this.name = name;
        this.totalRow = totalRow;
        this.totalCol = totalCol;
        this.owner = owner;
        //总排数和总列数决定座位列表的大小
        this.seats = new Seat[totalRow][totalCol];
        for (int i = 0; i < totalRow; i++) {
            for (int j = 0; j < totalCol; j++) {
                this.seats[i][j] = new Seat(i, j);
            }
        }
    }

    /**
     * 检测给定排号和列号的座位是否已经被订购
     */
    public boolean hasOwner(int row, int col) {
        return seats[row][col].getOwner() != null;
    }

    /**
     * 换座：原座位置空，新座位设置拥有者
     */
    public void changeSeat(int originalRow, int originalCol, int row, int col) {
        String owner = seats[originalRow][originalCol].getOwner();
        seats[originalRow][originalCol].setOwner(null);
        seats[row][col].setOwner(owner);
    }

    /**
     * 获取余票：拥有者为空的座位即为余票
     */
    public int getRestTickets() {
        int tickets = 0;
        for (Seat[] seatArr : seats) {
            for (Seat seat : seatArr) {
                if (seat.getOwner() == null) {
                    tickets++;
                }
            }
        }
        return tickets;
    }

    /**
     * 订购座位
     */
    public void orderSeat(int row, int col, String owner) {
        seats[row][col].setOwner(owner);
    }

    /**
     * 取消订座
     */
    public void cancelSeat(int row, int col) {
        seats[row][col].setOwner(null);
    }

    /**
     * 显示座位信息：未被订购的座位使用标准输出，已被订购的座位使用错误输出（控制台显示为红色）
     */
    public void showSeatInfo() {
        System.out.print(" ");
        for (int j = 0; j < totalCol; j++) {
            System.out.print(" " + j + " ");
        }
        System.out.println();
        for (int i = 0; i < totalRow; i++) {
            System.out.print(i);
            for (int j = 0; j < totalCol; j++) {
                PrintStream ps = seats[i][j].getOwner() == null ? System.out : System.err;
                ps.print(seats[i][j]);
                try {
                    Thread.sleep(20L);
                } catch (InterruptedException e) {
                    //忽略中断
                }
            }
            System.out.println();
        }
    }

    public String getId() {
        return id;
    }

    public void setId(String id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getTotalRow() {
        return totalRow;
    }

    public void setTotalRow(int totalRow) {
        this.totalRow = totalRow;
    }

    public int getTotalCol() {
        return totalCol;
    }

    public void setTotalCol(int totalCol) {
        this.totalCol = totalCol;
    }

    public Seat[][] getSeats() {
        return seats;
    }

    public void setSeats(Seat[][] seats) {
        this.seats = seats;
    }

    public String getOwner() {
        return owner;
    }

    public void setOwner(String owner) {
        this.owner = owner;
    }

    @Override
    public String toString() {
        return id + "\t" + name + "\t" + totalRow + "\t" + totalCol;
    }
}
```

### 1.2 命令编号必须唯一

## 第 2 章 服务端：把「功能实现」写成业务方法

### 2.1 先分层，再写功能

如果按课件的样子把所有逻辑都塞进 `MessageProcessTask` 的 `switch`，这个类最后会写到八百多行，
改一个功能要在一屏一屏的 `case` 里找。这里做一次小分层：

```text
cinema.platform.server
├── starter  CinemaPlatformServer     只负责 accept + 起线程
├── task     MessageProcessTask       只负责 收消息 → 分发 → 回发
├── service  UserService              账号：注册、登录、找回密码、解冻申请
│            AdminService             管理员：商家、用户、解冻申请
│            FilmService              影片增删改查
│            FilmHallService          影厅增删改查
│            FilmPlanService          影片计划增删改查 + 时间冲突
│            OrderService             订座、订单查询、改单、退单
└── util     FileUtil                 存档 / 读档
             FilmPlanValidator        影片计划时间冲突校验
```

规矩只有一条：**service 只算结果，不碰 Socket**。返回值统一由 `MessageProcessTask` 发出去。
好处是业务方法可以单独测，`switch` 里每个分支都只有一行。

### 2.2 时间冲突校验：`util/FilmPlanValidator.java`

课件的实体说明里写了“开始时间和结束时间主要用于检测影片播放计划是否冲突”，这里把它落成代码。
判定条件是**同一商家 + 同一影厅 + 同一天 + 时间段有交集**：

```java
package cinema.platform.server.util;

import org.zlf.cinema.platfrom.entity.FilmPlan;

import java.text.ParseException;
import java.text.SimpleDateFormat;

/**
 * 影片计划校验器：主要检测同一影厅的时间是否冲突
 * <p>
 * 冲突判定：同一商家、同一天、同一影厅，两条计划的时间段有交集。
 * 交集条件：begin1 < end2 && begin2 < end1
 */
public class FilmPlanValidator {

    private static final SimpleDateFormat FORMAT = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");

    /**
     * 检测两个影片计划是否冲突
     *
     * @param p1 已存在的计划
     * @param p2 待新增/待修改的计划
     * @return true 表示冲突，不能保存
     */
    public static boolean isConflictPlan(FilmPlan p1, FilmPlan p2) {
        //不同商家的影厅互不影响
        if (!p1.getOwner().getUsername().equals(p2.getOwner().getUsername())) {
            return false;
        }
        //不同影厅互不影响
        if (!p1.getHall().getId().equals(p2.getHall().getId())) {
            return false;
        }
        //不同日期互不影响
        if (!p1.getPlayDate().equals(p2.getPlayDate())) {
            return false;
        }
        String date = p1.getPlayDate();
        try {
            long begin1 = FORMAT.parse(date + " " + p1.getBeginTime()).getTime();
            long end1 = FORMAT.parse(date + " " + p1.getEndTime()).getTime();
            long begin2 = FORMAT.parse(date + " " + p2.getBeginTime()).getTime();
            long end2 = FORMAT.parse(date + " " + p2.getEndTime()).getTime();
            //形如：已有 10:00~12:00，新增 11:00~13:00 或 09:00~11:00 或 09:00~13:00 都算冲突
            return begin1 < end2 && begin2 < end1;
        } catch (ParseException e) {
            //时间格式错误，交给客户端/输入工具类拦截，这里不判冲突
            return false;
        }
    }
}
```

> 注意两个容易写错的地方：
> 1. 冲突判断不要写成三段 `case`，`begin1 < end2 && begin2 < end1` 一行就够，边界（前一场 12:00 结束、后一场 12:00 开始）不算冲突；
> 2. 不同影厅可以同时放映，所以必须加影厅判断，否则同一个影院两场不同厅的电影会被误拦。

### 2.3 `service/UserService.java`：注册、登录、找回密码、解冻申请

对应的课件要求（第四章「登录界面」）：

- 注册：1 成功 / 0 失败 / -1 账号已被注册；
- 入驻申请：1 成功 / 0 失败 / -1 账号或影院重复；
- 登录：1 成功 / 0 失败 / -1 账号不存在 / 2 审批中 / 3 冻结，并且要回传身份；
- 找回密码：安全码正确返回密码，否则返回 `null`；
- 申请解冻：1 / 0 / -1 账号不存在 / -2 状态不允许 / -3 已有待处理申请。

```java
package cinema.platform.server.service;

import cinema.platform.server.util.FileUtil;
import org.zlf.cinema.platfrom.entity.Seller;
import org.zlf.cinema.platfrom.entity.UnfrozenApply;
import org.zlf.cinema.platfrom.entity.User;
import org.zlf.cinema.platfrom.util.IdGenerator;
import org.zlf.cinema.platfrom.vo.LoginResult;

import java.util.List;

/**
 * 账号业务：注册、登录、找回密码、申请解冻
 * <p>
 * 约定：这一层只负责“算结果”，不碰 Socket；
 * 把结果交回 MessageProcessTask，由它统一发送给客户端。
 */
public class UserService {

    /**
     * 注册 / 入驻申请
     * <p>
     * 普通用户和商家都往 user.obj 里存，用 Seller 是否为 User 的子类来区分身份，
     * 所以注册和入驻申请可以共用这一段逻辑。
     *
     * @param data User（普通用户）或 Seller（商家）
     * @return 1-成功，0-失败，-1-账号或影院名称已被使用
     */
    public static Integer register(Object data) {
        User user = (User) data;
        List<User> users = FileUtil.readData(FileUtil.USER_FILE);
        for (User u : users) {
            //账号唯一
            if (u.getUsername().equals(user.getUsername())) {
                return -1;
            }
            //商家的影院名称也唯一
            if (u instanceof Seller && user instanceof Seller) {
                Seller oldSeller = (Seller) u;
                Seller newSeller = (Seller) user;
                if (oldSeller.getCinemaName().equals(newSeller.getCinemaName())) {
                    return -1;
                }
            }
        }
        users.add(user);
        return FileUtil.saveData(users, FileUtil.USER_FILE) ? 1 : 0;
    }

    /**
     * 登录
     *
     * @param data 只填了账号、密码的 User
     * @return LoginResult：标识 + 登录者身份
     */
    public static LoginResult login(User data) {
        List<User> users = FileUtil.readData(FileUtil.USER_FILE);
        //系统第一次运行，内置一个管理员账号，否则没有人能审核商家
        boolean hasManager = false;
        for (User u : users) {
            if (u.getRole() == User.Role.MANAGER) {
                hasManager = true;
                break;
            }
        }
        if (!hasManager) {
            User manager = new User("admin", "123456", "ZLF");
            manager.setRole(User.Role.MANAGER);
            manager.setState(1);
            users.add(manager);
            FileUtil.saveData(users, FileUtil.USER_FILE);
        }

        for (User u : users) {
            if (!u.getUsername().equals(data.getUsername())) {
                continue;
            }
            //账号存在，再判断状态
            if (u.getState() == 2) {
                return new LoginResult(LoginResult.FROZEN);
            }
            if (u.getState() == 0) {
                return new LoginResult(LoginResult.AUDITING);
            }
            if (u.getState() == -1) {
                return new LoginResult(LoginResult.REJECTED);
            }
            if (!u.getPassword().equals(data.getPassword())) {
                return new LoginResult(LoginResult.FAIL);
            }
            //登录成功：把身份带回去，但密码、安全码不能回传
            User loginUser = copyOf(u);
            loginUser.setPassword(null);
            loginUser.setSecurityCode(null);
            return new LoginResult(LoginResult.SUCCESS, loginUser);
        }
        return new LoginResult(LoginResult.NOT_EXIST);
    }

    /**
     * 找回密码
     *
     * @param data 账号 + 安全码
     * @return 安全码正确返回密码，否则返回 null
     */
    public static String getPasswordBack(User data) {
        List<User> users = FileUtil.readData(FileUtil.USER_FILE);
        for (User u : users) {
            if (!u.getUsername().equals(data.getUsername())) {
                continue;
            }
            if (u.getSecurityCode() != null && u.getSecurityCode().equals(data.getSecurityCode())) {
                return u.getPassword();
            }
            return null;
        }
        return null;
    }

    /**
     * 申请解冻
     *
     * @param apply 账号 + 解冻理由
     * @return 1-成功，0-失败，-1-账号不存在，-2-账号状态不允许申请，-3-已有待处理的申请
     */
    public static Integer unfrozenApply(UnfrozenApply apply) {
        List<User> users = FileUtil.readData(FileUtil.USER_FILE);
        User target = null;
        for (User u : users) {
            if (u.getUsername().equals(apply.getUsername())) {
                target = u;
                break;
            }
        }
        if (target == null) {
            return -1;
        }
        //只有被冻结的账号才需要解冻
        if (target.getState() != 2) {
            return -2;
        }
        List<UnfrozenApply> applies = FileUtil.readData(FileUtil.UNFROZEN_APPLY_FILE);
        for (UnfrozenApply ua : applies) {
            if (ua.getUsername().equals(apply.getUsername()) && ua.getState() == 0) {
                return -3;
            }
        }
        apply.setId(IdGenerator.generateId(10));
        apply.setState(0);
        applies.add(apply);
        return FileUtil.saveData(applies, FileUtil.UNFROZEN_APPLY_FILE) ? 1 : 0;
    }

    /**
     * 复制一个用户对象：需要把“去掉密码的副本”发给客户端，
     * 不能直接把存档里的对象置空，否则会把密码写没了。
     */
    private static User copyOf(User u) {
        User copy;
        if (u instanceof Seller) {
            Seller s = (Seller) u;
            copy = new Seller(s.getUsername(), s.getPassword(), s.getSecurityCode(),
                    s.getCinemaAddress(), s.getCinemaName());
        } else {
            copy = new User(u.getUsername(), u.getPassword(), u.getSecurityCode());
        }
        copy.setRole(u.getRole());
        copy.setState(u.getState());
        return copy;
    }
}
```

> 三个要点：
> 1. **注册和入驻申请共用一段逻辑**：`Seller` 是 `User` 的子类，两者都存进 `user.obj`，用 `instanceof` 区分，不必写两份；
> 2. **登录成功要复制一份用户再发**：直接把存档里的对象 `setPassword(null)` 再保存，会把密码写没。所以 `copyOf()` 复制后只清空副本；
> 3. **第一次运行自动建管理员** `admin / 123456`：否则没有任何账号能审核商家，系统会卡在第一步。

```java
     * 审批解冻申请

        String id = (String) data.get("id");
        Integer state = (Integer) data.get("state");
        List<UnfrozenApply> applies = FileUtil.readData(FileUtil.UNFROZEN_APPLY_FILE);
        for (UnfrozenApply apply : applies) {
            if (!apply.getId().equals(id)) {
                continue;
            }
            if (apply.getState() != 0) {
                return -2;
            }
            apply.setState(state);
            if (state != 1) {
                //驳回：只改申请状态
                return FileUtil.saveData(applies, FileUtil.UNFROZEN_APPLY_FILE) ? 1 : 0;
            }
            //通过：申请状态和账号状态都要改
            List<User> users = FileUtil.readData(FileUtil.USER_FILE);
            for (User u : users) {
                if (u.getUsername().equals(apply.getUsername())) {
                    u.setState(1);
                    break;
                }
            }
            boolean success = FileUtil.saveData(users, FileUtil.USER_FILE);
            if (success) {
                success = FileUtil.saveData(applies, FileUtil.UNFROZEN_APPLY_FILE);
            }
            return success ? 1 : 0;
        }
        return -1;
    }
}
```

> 审批解冻是整个项目里唯一同时改两个文件的操作（`user.obj` + `unfrozenApply.obj`），
> 顺序是“先改账号、后改申请”，两个都成功才返回 1。

### 2.7 `service/FilmPlanService.java`：影片计划 + 冲突处理

课件要求：增加要选影片、影厅、日期、起止时间；修改只改日期时间；删除按编号；查看按影片名称模糊匹配。

```java
package cinema.platform.server.service;

import cinema.platform.server.util.FileUtil;
import cinema.platform.server.util.FilmPlanValidator;
import org.zlf.cinema.platfrom.entity.FilmPlan;
import org.zlf.cinema.platfrom.util.IdGenerator;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

/**
 * 影片计划业务：增删改查 + 时间冲突检测
 */
public class FilmPlanService {

    /**
     * 增加影片计划
     *
     * @return 1-成功，0-失败，-1-与已有计划时间冲突
     */

        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        for (FilmPlan p : plans) {
            if (FilmPlanValidator.isConflictPlan(p, plan)) {
                return -1;
            }
        }
        plan.setId(IdGenerator.generateId(10));
        plans.add(plan);
        return FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE) ? 1 : 0;

     * 修改影片计划：只改日期和时间，影片、影厅不变
     *
     * @param data id,date,beginTime,endTime,owner
     * @return 1-成功，0-失败，-1-计划不存在，-2-修改后时间冲突
     */
    public static Integer update(Map<String, Object> data) {
        String id = (String) data.get("id");
        String date = (String) data.get("date");
        String beginTime = (String) data.get("beginTime");
        String endTime = (String) data.get("endTime");
        String owner = (String) data.get("owner");

        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        FilmPlan target = null;
        int index = -1;
        for (int i = 0; i < plans.size(); i++) {
            FilmPlan p = plans.get(i);
            if (p.getId().equals(id) && p.getOwner().getUsername().equals(owner)) {
                target = p;
                index = i;
                break;
            }
        }
        if (target == null) {
            return -1;
        }
        //先把自己从列表里拿出来，再和自己以外的计划比时间
        plans.remove(index);
        target.setPlayDate(date);
        target.setBeginTime(beginTime);
        target.setEndTime(endTime);
        for (FilmPlan p : plans) {
            if (FilmPlanValidator.isConflictPlan(p, target)) {
                return -2;
            }
        }
        plans.add(target);
        return FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE) ? 1 : 0;
    }

    /**
     * 删除影片计划
     *
     * @param data id-计划编号，owner-商家账号
     * @return 1-成功，0-失败，-1-计划不存在

        String owner = (String) data.get("owner");
        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        for (int i = 0; i < plans.size(); i++) {
            FilmPlan p = plans.get(i);
            if (p.getId().equals(id) && p.getOwner().getUsername().equals(owner)) {
                plans.remove(i);
                return FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE) ? 1 : 0;
            }
        }
        return -1;

     *
     * @param data filmName-影片名称（y/Y 表示全部，否则模糊匹配），owner-商家账号（不带表示查全部商家的）
     */

        String filmName = (String) data.get("filmName");
        String owner = (String) data.get("owner");
        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        List<FilmPlan> result = new ArrayList<>();
        for (FilmPlan p : plans) {

            //owner 为空表示普通用户，可以看所有商家的排片

            result.add(p);
        }
        return result;

        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        for (FilmPlan p : plans) {
            if (p.getId().equals(id)) {
                return p;
            }
        }
        return null;
    }
}
```

```java
 * <p>
 * 注意：座位是存在“影片计划里的影厅”中的，所以订座/退座要同时改动
 * 影片计划文件（座位图）和订单文件，两个文件要一起保存。
 */
public class OrderService {

    /**
     * 在线订座：占座 + 生成订单
     *
     * @param data id-影片计划编号，row-排号，col-列号，owner-订票用户账号
     * @return 1-成功，0-失败（含行列越界），-1-影片计划不存在，-2-座位已被订购
     */
    public static Integer orderSeatOnline(Map<String, Object> data) {
        String id = (String) data.get("id");
        Integer row = (Integer) data.get("row");
        Integer col = (Integer) data.get("col");
        String owner = (String) data.get("owner");

        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        FilmPlan plan = null;
        for (FilmPlan p : plans) {
            if (p.getId().equals(id)) {
                plan = p;
                break;
            }
        }
        if (plan == null) {
            return -1;
        }
        FilmHall hall = plan.getHall();
        //行列必须落在座位图范围内，非法值按失败处理，不能让数组越界异常炸掉本次处理
        if (row == null || col == null || row < 0 || row >= hall.getTotalRow() || col < 0 || col >= hall.getTotalCol()) {
            return 0;
        }
        //服务端必须再判一次，客户端看到的是旧座位图，别人可能已经抢先订了
        if (hall.hasOwner(row, col)) {
            return -2;
        }
        hall.orderSeat(row, col, owner);

        Order order = new Order();
        order.setId(IdGenerator.generateId(10));
        order.setFilmPlanId(plan.getId());
        order.setFilmName(plan.getFilm().getName());
        order.setFilmHallName(hall.getName());
        order.setPlayDate(plan.getPlayDate());
        order.setBeginTime(plan.getBeginTime());
        order.setEndTime(plan.getEndTime());
        order.setRow(row);
        order.setCol(col);
        order.setUser(owner);
        order.setSeller(plan.getOwner());
        order.setState(1);

        List<Order> orders = FileUtil.readData(FileUtil.ORDER_FILE);
        orders.add(order);
        boolean success = FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE);
        if (success) {
            success = FileUtil.saveData(orders, FileUtil.ORDER_FILE);
        }
        return success ? 1 : 0;
    }

    /**
     * 查看订单：商家只看自己影院的，普通用户只看自己的
     *
     * @param user 登录者
     */
    public static List<Order> view(User user) {
        List<Order> orders = FileUtil.readData(FileUtil.ORDER_FILE);
        List<Order> result = new ArrayList<>();
        for (Order o : orders) {
            if (user instanceof Seller) {
                if (o.getSeller() != null && o.getSeller().getUsername().equals(user.getUsername())) {
                    result.add(o);
                }
            } else {
                if (o.getUser().equals(user.getUsername())) {
                    result.add(o);
                }
            }
        }
        return result;
    }

    /**
     * 修改订单：换座位（只能修改自己的订单）
     *
     * @param data id-订单编号，row-新排号，col-新列号，owner-用户账号
     * @return 1-成功，0-失败（含行列越界），-1-订单或影片计划不存在（含不是自己的订单），-2-新座位已被订购
     */
    public static Integer update(Map<String, Object> data) {
        String id = (String) data.get("id");
        Integer row = (Integer) data.get("row");
        Integer col = (Integer) data.get("col");
        String owner = (String) data.get("owner");

        List<Order> orders = FileUtil.readData(FileUtil.ORDER_FILE);
        Order order = null;
        for (Order o : orders) {
            if (o.getId().equals(id) && o.getUser().equals(owner)) {
                order = o;
                break;
            }
        }
        if (order == null) {
            return -1;
        }
        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        FilmPlan plan = null;
        for (FilmPlan p : plans) {
            if (p.getId().equals(order.getFilmPlanId())) {
                plan = p;
                break;
            }
        }
        if (plan == null) {
            return -1;
        }
        FilmHall hall = plan.getHall();
        //行列必须落在座位图范围内，非法值按失败处理，不能让数组越界异常炸掉本次处理
        if (row == null || col == null || row < 0 || row >= hall.getTotalRow() || col < 0 || col >= hall.getTotalCol()) {
            return 0;
        }
        if (hall.hasOwner(row, col)) {
            return -2;
        }
        hall.changeSeat(order.getRow(), order.getCol(), row, col);
        order.setRow(row);
        order.setCol(col);

        boolean success = FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE);
        if (success) {
            success = FileUtil.saveData(orders, FileUtil.ORDER_FILE);
        }
        return success ? 1 : 0;
    }

    /**
     * 取消订单：退座 + 订单状态改为已退订
     *
     * @param data id-订单编号，owner-用户账号（只能取消自己的订单）
     * @return 1-成功，0-失败，-1-订单不存在，-2-订单已经是退订状态
     */
    public static Integer cancel(Map<String, Object> data) {
        String id = (String) data.get("id");
        String owner = (String) data.get("owner");

        List<Order> orders = FileUtil.readData(FileUtil.ORDER_FILE);
        Order order = null;
        for (Order o : orders) {
            if (o.getId().equals(id) && o.getUser().equals(owner)) {
                order = o;
                break;
            }
        }
        if (order == null) {
            return -1;
        }
        if (order.getState() == 0) {
            return -2;
        }
        List<FilmPlan> plans = FileUtil.readData(FileUtil.FILM_PLAN_FILE);
        FilmPlan plan = null;
        for (FilmPlan p : plans) {
            if (p.getId().equals(order.getFilmPlanId())) {
                plan = p;
                break;
            }
        }
        if (plan == null) {
            return -1;
        }
        plan.getHall().cancelSeat(order.getRow(), order.getCol());
        order.setState(0);

        boolean success = FileUtil.saveData(plans, FileUtil.FILM_PLAN_FILE);
        if (success) {
            success = FileUtil.saveData(orders, FileUtil.ORDER_FILE);
        }
        return success ? 1 : 0;
    }

    /**
     * 通过编号查订单（修改订单前回显用）
     */
    public static Order getById(String id) {
        List<Order> orders = FileUtil.readData(FileUtil.ORDER_FILE);
        for (Order o : orders) {
            if (o.getId().equals(id)) {
                return o;
            }
        }
        return null;
    }
}
```

> 四个要点：
> 1. **服务端必须再判一次座位是否被占**：客户端拿到的座位图可能是几秒前的，别人已经抢先订了；
> 2. **订座成功后两个文件都要存**：先存 `filmPlan.obj`（座位图），再存 `order.obj`，任一失败都返回 0；
> 3. **退单要 `cancelSeat`**：只把订单状态改成 0 而座位不释放，余票会永远少一张；
> 4. **商家看订单和用户看订单走同一个命令**，靠 `data` 传进来的登录者身份（`Seller` / `User`）区分。

```java
package cinema.platform.server.task;

import cinema.platform.server.service.AdminService;
import cinema.platform.server.service.FilmHallService;
import cinema.platform.server.service.FilmPlanService;
import cinema.platform.server.service.FilmService;

import org.zlf.cinema.platfrom.message.Message;
import org.zlf.cinema.platfrom.util.SocketUtil;

import java.net.Socket;
import java.util.Map;

/**
 * 消息处理任务
 * <p>
 * 一个客户端连接对应一个任务、一个线程。
 * 这一层只做三件事：收消息 → 看命令 → 交给对应的业务方法，
 * 最后把业务方法返回的结果原样发回客户端。
 * 真正的处理逻辑都在 service 包里，这样任务类不会越写越长。
 */
public class MessageProcessTask implements Runnable {

    private Socket socket;

    public MessageProcessTask(Socket socket) {
        this.socket = socket;
    }

    @Override
    public void run() {
        try {
            //1.接收客户端消息
            Message message = SocketUtil.receiveMsg(socket);
            if (message == null) {
                return;
            }
            //2.取出消息携带的数据
            Object data = message.getData();
            //3.根据命令分发
            Object result = null;
            switch (message.getCommand()) {
                //========== 登录界面 ==========
                case Command.REGISTER://注册
                case Command.ENTRY_APPLY://入驻申请（同样是注册，数据是 Seller）
                    result = UserService.register(data);
                    break;
                case Command.LOGIN://登录
                    result = UserService.login((User) data);
                    break;
                case Command.VIEW_ENTRY_APPLY://查看入驻申请
                    result = AdminService.viewEntryApply((String) data);
                    break;
                case Command.GET_PASSWORD_BACK://找回密码
                    result = UserService.getPasswordBack((User) data);
                    break;
                case Command.UNFROZEN_APPLY://申请解冻
                    result = UserService.unfrozenApply((UnfrozenApply) data);
                    break;
                //========== 管理员主界面 ==========
                case Command.VIEW_SELLERS://查看商家
                    result = AdminService.viewSellers((String) data);
                    break;
                case Command.AUDIT_SELLER://审核商家
                    result = AdminService.auditSeller(map(data));
                    break;
                case Command.FROZEN_SELLER://冻结商家
                    result = AdminService.frozenSeller((String) data);
                    break;
                case Command.VIEW_USERS://查看用户
                    result = AdminService.viewUsers();
                    break;
                case Command.FROZEN_USER://冻结用户
                    result = AdminService.frozenUser((String) data);
                    break;
                case Command.VIEW_UNFROZEN_APPLIES://查看解冻申请
                    result = AdminService.viewUnfrozenApplies();
                    break;
                case Command.AUDIT_UNFROZEN_APPLY://审批解冻申请
                    result = AdminService.auditUnfrozenApply(map(data));
                    break;
                //========== 商家主界面：影厅管理 ==========
                case Command.VIEW_FILM_HALLS://查看影厅
                    result = FilmHallService.view((String) data);
                    break;
                case Command.ADD_FILM_HALL://增加影厅
                    result = FilmHallService.add((FilmHall) data);
                    break;
                case Command.UPDATE_FILM_HALL://修改影厅
                    result = FilmHallService.update((FilmHall) data);
                    break;
                case Command.DELETE_FILM_HALL://删除影厅
                    result = FilmHallService.delete(map(data));
                    break;
                //========== 商家主界面：影片管理 ==========
                case Command.VIEW_FILMS://查看影片
                    result = FilmService.view(map(data));
                    break;
                case Command.ADD_FILM://增加影片
                    result = FilmService.add((Film) data);
                    break;
                case Command.UPDATE_FILM://修改影片
                    result = FilmService.update((Film) data);
                    break;
                case Command.DELETE_FILM://删除影片
                    result = FilmService.delete(map(data));
                    break;
                //========== 商家/用户：影片计划 ==========
                case Command.VIEW_FILM_PLANS://查看影片计划
                    result = FilmPlanService.view(map(data));
                    break;
                case Command.ADD_FILM_PLAN://增加影片计划
                    result = FilmPlanService.add((FilmPlan) data);
                    break;
                case Command.UPDATE_FILM_PLAN://修改影片计划
                    result = FilmPlanService.update(map(data));
                    break;
                case Command.DELETE_FILM_PLAN://删除影片计划
                    result = FilmPlanService.delete(map(data));
                    break;
                case Command.GET_FILM_PLAN_BY_ID://按编号查影片计划
                    result = FilmPlanService.getById((String) data);
                    break;
                //========== 商家/用户：订单 ==========
                case Command.ORDER_SEAT_ONLINE://在线订座
                    result = OrderService.orderSeatOnline(map(data));
                    break;
                case Command.VIEW_ORDERS://查看订单
                    result = OrderService.view((User) data);
                    break;
                case Command.UPDATE_ORDER://修改订单
                    result = OrderService.update(map(data));
                    break;
                case Command.CANCEL_ORDER://取消订单
                    result = OrderService.cancel(map(data));
                    break;
                case Command.GET_ORDER_BY_ID://按编号查订单
                    result = OrderService.getById((String) data);
                    break;
                default:
                    //SHOW_CHILDREN、QUIT 这类命令只在客户端内部使用，不会发到服务器
                    result = null;
                    break;
            }
            //4.把处理结果发回客户端
            SocketUtil.sendMsg(socket, result);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    /**
     * Message 的泛型在接收端会被擦除，这里统一转成 Map 使用
     */
    @SuppressWarnings("unchecked")
    private static Map<String, Object> map(Object data) {
        return (Map<String, Object>) data;
    }
}
```

## 第 3 章 客户端：把「功能实现」写成用户行为

### 3.1 客户端的三步套路

`UserAction` 里 30 个方法，全都是同一个套路，照着一个写就行：

```text
① 用 InputUtil 收集数据
② MessageSender.sendMsg(命令, 数据) 发给服务器
③ 按返回的标识打印提示（1/0/-1/2/-2/-3）
```

唯一的例外是 `login()`，它把整个 `LoginResult` 交给启动类，由启动类决定进哪个主菜单。

### 3.2 `action/UserAction.java`

```java
    /**
     * 冻结商家
     */
    public static void frozenSeller() {
        String username = InputUtil.getInputText("请输入商家账号：");
        Integer result = MessageSender.sendMsg(Command.FROZEN_SELLER, username);
        if (result == null || result == 0) {
            System.out.println("冻结失败，请稍后重试");
```

> 几个踩过的坑，直接在代码里改掉了：
> 1. 选座位时排号、列号的范围是 `0 ~ 总排数-1`，写成 `0 ~ 总排数` 会 `ArrayIndexOutOfBoundsException`；
> 2. 订座失败（座位被别人抢了）要 `continue` 回到选座，而不是直接结束；
> 3. 改订单前先查一次订单、再查一次影片计划，确认订单是自己的、座位图是最新的；
> 4. 日期、时间一律用 `InputUtil.getInputDate` 校验格式，避免 `SimpleDateFormat` 在后面抛异常。

```java
    /**
     * 登录：根据 LoginResult 的标识给出提示，成功则进入对应身份的主菜单
     */
    private static void login(Menu[] menus) {
        LoginResult result = UserAction.login();
        if (result == null) {
            System.out.println("服务器无响应，请检查服务端是否已启动");
            showInterface(menus);
            return;
        }
        switch (result.getCode()) {
            case LoginResult.SUCCESS:
                currentUser = result.getUser();
                System.out.println("登录成功，欢迎您：" + currentUser.getUsername());
                showUserMenus();
                break;
            case LoginResult.AUDITING:
                System.out.println("账号正在审批中，请耐心等待");
                showInterface(menus);
                break;
            case LoginResult.FROZEN:
                System.out.println("账号已被冻结，请提交解冻申请");
                showInterface(menus);
                break;
            case LoginResult.REJECTED:
                System.out.println("账号审核未通过");
                showInterface(menus);
                break;
            case LoginResult.NOT_EXIST:
                System.out.println("账号不存在，请先注册");
                showInterface(menus);
                break;
            default:
                System.out.println("账号或密码错误，请重新登录");
                showInterface(menus);
                break;
        }
    }

    /**
     * 按登录者的角色展示对应的主菜单
     */
    private static void showUserMenus() {
        User.Role role = currentUser.getRole();
        if (role == User.Role.MANAGER) {
            showInterface(MenuManager.MANAGER_MENUS);
        } else if (role == User.Role.SELLER) {
            showInterface(MenuManager.SELLER_MENUS);
        } else {
            showInterface(MenuManager.USER_MENUS);
        }
    }
}
```

> `currentUser` 是静态字段，登录成功后保存下来；商家相关操作（加影片、加影厅、加计划）都要从它身上取账号，
> 这样服务端才知道这条数据属于谁。返回登录时要把它置空，避免拿着上一个人的身份继续操作。

### 4.4 常见报错对照

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 客户端 `Connection refused` | 服务端没启动，或端口不是 8888 | 先起服务端；确认 `MessageSender` 的 `PORT` 与 `CinemaPlatformServer` 的构造参数一致 |
| 服务端启动即 `BindException: Address already in use` | 上一次的服务端还在跑 | 结束旧的 `java` 进程，或换端口 |
| `NotSerializableException: org.zlf...entity.User` | 实体没实现 `Serializable` | 按 1.1 给所有实体加 `implements Serializable` |
| 编译报 `duplicate case label` | `Command` 里有重复编号 | 按 1.2 换成唯一编号 |
| 客户端能连上但没反应 | 服务端 `switch` 里漏了这个 `case`，返回了 `null` | 对照 0.2 的表补齐分支 |
| 登录后点“返回登录”又弹出注册 | 菜单命令写成了 `Command.REGISTER` | 按 1.4 改成 `GO_BACK_LOGIN` |
| 订座时 `ArrayIndexOutOfBoundsException` | 排号列号范围用了 `0~总排数` | 改成 `0~总排数-1`（客户端 + 服务端都判） |
| 列表打印出一串 `org.zlf...@1b6d3586` | 实体没重写 `toString()` | 按 1.1 补 `toString()` |
| 第二次启动后数据没了 | 服务端工作目录变了，`data/` 建到了别处 | 固定服务端的运行目录（IDEA 里看 `Working directory`） |
